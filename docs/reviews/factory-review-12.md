## (c) Remaining and new proposals, prioritized

1. **A repository without `package.json` records `commands.install = pnpm install`, and the first wave fails `INSTALL-FAILED`.** `bin/agentic-factory.mjs:58` builds `commands.install` from the package manager alone (`${pm} install` when no lockfile exists), and `:51` picks `pnpm` from PATH even when no `package.json` exists; `:152-154` then offers `install: pnpm install` as the recommended default of question 10. `controller/integ-wave.sh:24` and `:41` run a non-empty `INSTALL_CMD` and treat its failure after the merge as fatal (experiment (n): `[ERR_PNPM_NO_PKG_MANIFEST]`, exit 1). A Python, Go or docs project (the guardrails count `_test.py`, `Test.java`, `func Test` tests, `templates/tools/factory-guardrails.mjs:32`) that fills in `verify` by hand keeps the install default by pressing Enter. Change: in `detect()` return `install: ""` (and `pm` only for the hook commands) when no `package.json` exists, and print `install: (none)`. Test: repo without `package.json` → `commands.install` empty → `integ-wave.sh` on a reviewed task with a hand-set `verify` → `PUSHED main`. **debt** (the documented first-hour input is a Node repo; with `--yes` the wave is refused earlier by `VERIFY-MISSING`; F04 covers the verify half).
2. **The stale-bare probe keys on the bare's `HEAD` symref, so the stock-git shape (bare `HEAD` → `master`, project on `main`) still adopts the stale bare.** `bin/agentic-factory.mjs:91` runs `git -C <bare> rev-parse --verify -q HEAD`; `git init --bare` writes `HEAD` → `refs/heads/master` unless `init.defaultBranch` is set (Apple's git sets `main` in its system gitconfig, stock Linux git does not), while the pushed branch is `main`, so the probe sees "empty" (experiment (c4)): `using the existing local bare remote`, the adoption push is rejected, `init` exits 1 (fixed) but leaves `origin` on the stale bare, `core.hooksPath` armed and `factory.config.json` written; the message at `:351` is cut at 200 characters before the `! [rejected]` line, and a re-run says `Already initialised` and never retries. Change: probe with `git -C <bare> show-ref --heads` (any branch) or `rev-parse --verify -q refs/heads/<branch>`; on a failed adoption push print the last stderr line and the `rm -rf <bare>` remedy, and remove `origin` as `foreign()` does. Test: bare with `HEAD` → unborn `master` and a foreign `main`, project on `main` without a commit → exit 1 `different history`, `git remote` empty. **debt** (needs stock git without `init.defaultBranch` plus `git init -b main` plus a start-over without a commit; the failure is printed).

Fixes for a shared host and the preview, plus two documented ways of working.

**Fixes**
- **Cleanup on a shared host (#16):** `cleanup.mjs` takes the integration worktree from `git worktree list` and compares paths exactly, so it no longer closes another project's wave terminals. A project that patched this locally can drop the patch after `update`.
- **Blocked tickets (#15):** `issues.mjs ready` leaves out issues with open blockers; `tasks.mjs list ready` leaves out tasks whose `Depends on:` names a task that is not `integrated`. `CONTROLLER.md` now says who sets that: every wave merges a last branch that sets `Status: integrated` for its tasks, and issues are closed after the push. Without this step, dependents would never start.
- **Preview env file (#13):** a path with `~` is found; a missing or unreadable env file, or a line that is not `NAME=value`, starts nothing. `export NAME=value` lines are accepted. **A preview may have run without its env file before this release:** check what it showed.
- **Preview under launchd (#14):** the plist sets `AbandonProcessGroup`. **Existing plists need the key added and a reload** (`launchctl bootout` and `bootstrap` of the preview agent), or a multi-stage start command still dies.

**Documented**
- **Design lane:** when the human asks, the Front agent shapes one surface directly on a branch while the human reviews on a separate port; tests, review and gate follow as a hardening ticket. A review now compares the result with signed-off screens: a missing control or flow fails, other differences go to acceptance.
- **Front agent on the server:** piloted in one project, beside the Controller in the same Orca. Not supported by `start`, `statuswatch.mjs` or `doctor` yet; do not set it up unless the project chose it.

After updating, run `agentic-factory update` in each project.

Known gaps: F49 (symlinked worktree paths keep a project's own wave terminals open), F50 (`blockedBy` not yet checked against a real blocker).

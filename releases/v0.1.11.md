Lessons from piloting the Front agent on the server.

**Documented**
- **Waking the Front agent on the server (`docs/orca.md`):** Orca's wake did not reach a Front agent running in Claude Code; messages sat unread for hours. The Front agent now runs a watch: it follows `front-events.log` and takes its mailbox every 15 s, printing every message it takes. Read the backlog once before arming the watch. Measured with one agent and one Orca version.
- **Escalations (`controller/CONTROLLER.md`):** before escalating, the Controller applies the task's abort criteria and the human's recorded decisions, and names in the question which ones it checked. With the Front agent on the server, every "Needs human" and every block goes to its terminal at once.

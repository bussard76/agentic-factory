The Front agent is now a candid development partner instead of an order taker.

- `FRONT_AGENT.md` has a new section on how the Front agent works with the human: full transparency, including its own mistakes and how sure it is; it says plainly and with reasons when it thinks an idea is weak; it holds its position until it hears a new argument or fact, restates its reasons once, then asks the human to decide. After the decision it carries it out fully and records its dissent next to the decision. No flattery.
- `AGENTS.md` gets one line for every agent: tell the coordinator your doubts, risks or a better way, never hide a problem, then do the task as given unless the coordinator changes it.
- `docs/roles.md` describes the Front agent as a development partner.

After updating, run `agentic-factory update` in each project to regenerate the Front agent bundle. In a project that checks in `AGENTS.md`, the file is protected: adopting the new line there needs an ADR.
